# 乐学

面向 3–12 岁儿童、默认按 4 岁起点配置的手机 PWA 早教工作台。应用包含国学、识字、数学、英语、控笔和科学启蒙六个模块，提供适龄每日任务、真实学习表现记录、宠物成长、星光奖励、家长周报以及离线数据保存。

公开部署版支持匿名设备会话、家庭账号、多孩子档案、PostgreSQL 云备份与版本冲突保护。孩子无需登录；家长登录后获得自动同步和换机恢复。本地 IndexedDB 仍作为离线学习数据层。

## 本地运行

```bash
pnpm install
cp .env.example .env
# 填入千问 API Key 与工作空间 ID 后启动
pnpm dev
```

生产构建与自动化测试：

```bash
CI=true pnpm test
CI=true pnpm build
CI=true pnpm preview
```

构建产物位于 `dist/`，需要与 server/ 一起部署，或由静态站点反向代理 /api/tts 至语音服务。项目使用相对资源路径和 Hash 路由，部署在域名根目录或子目录均可使用。

所有应用配置统一放在根目录 `.env`；开发、预览和脚本不再读取 `.env.local` 或模式专属配置。旧配置迁移和生产单文件部署见 [统一配置说明](docs/统一env配置.md)。

## Docker 与自动发布

本项目支持 Docker 部署。推送 `vX.Y.Z` 版本标签后，GitHub Actions 会自动测试、构建并推送 GHCR 灾备镜像，创建 GitHub Release，再通过 SSH 上传轻量应用代码包。阿里云复用本机缓存的 Node.js、FFmpeg 和运行依赖环境，在本机离线生成版本镜像；只有首次部署或环境标识变化时才上传运行环境镜像，生产机无需跨境拉取 GHCR。新容器启动或健康检查失败时会恢复上一镜像。

服务器参数、GitHub Secrets、首次发布、回滚和客户端缓存更新策略见 [自动发布与阿里云部署](docs/自动发布与阿里云部署.md)。

PostgreSQL、家庭账号、接口额度、运营后台和阿里云 OSS 语音缓存的宝塔部署方式见 [宝塔部署账号与成本控制](docs/宝塔部署账号与成本控制.md)。

本地验证容器：

```bash
docker build -t lexue:local .
docker run --rm -v "$PWD/.env:/app/.env:ro" -e PORT=80 -p 8080:80 lexue:local
```

## 手机安装

- Android：使用 Chrome 等浏览器打开 HTTPS 地址，点击页面内“添加”，或从浏览器菜单选择“安装应用”。
- iPhone/iPad：使用 Safari 打开，点击“分享”，选择“添加到主屏幕”。
- PWA 安装和 Service Worker 在正式环境中需要 HTTPS；`localhost` 本地预览除外。

首次打开后，应用壳、示例题库、图标会被缓存；语音朗读需要联网，成功播放的音频会进入浏览器缓存，服务端同时使用本机目录和可选的阿里云 OSS 共享缓存。更新就绪时页面会显示刷新提示。

当前内置课程共 2089 项：320 首小学与初中古诗词、11 篇经典古文、665 个常用字、240 道六阶数学任务、26 个英文字母、270 个主题词、12 本原创启蒙绘本、443 个描红目标和 102 个科学任务。英语先按每天 2 个新字母学习 A–Z，穿插已学字母复习；认识全部 26 个字母后，再进入主题词和每周 3 本绘本。

古诗词按小学和初中年级设置适合年龄，作者统一显示并朗读“朝代简称·作者”。古诗原文属于公版作品，篇目和年级整理参考 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 与 [gushi_k12](https://github.com/xuegushi/gushi_k12) 的结构化资料。

## 数据与家长入口

- 设置、题库、每日清单、逐条学习表现、完成事件、奖励流水、宠物、兑换和报告先存入 IndexedDB；相关的完成、奖励和日报采用同一事务保存。登录家庭账号后，版本化备份会同步到 PostgreSQL。
- 家长中心“历史”页可按日期、模块、完成状态、名称或内容 ID 查询每天每个模块的具体内容；资料库和今日任务的资料选择器会同步标记“已学/未学”。
- 家长看板按周汇总新学、复习、独立完成、选择题首次答对和待巩固内容。旧版本完成记录会保留，但不会被推断为“独立掌握”。
- 应用会申请浏览器持久存储，但清理浏览器网站数据、卸载 PWA 或系统回收仍可能删除本地记录。
- 家长应从“家长中心 → 数据”定期导出 JSON 完整备份；恢复前应用会校验嵌套数据、自动下载当前数据的恢复前备份，并补齐当天学习计划。
- 家长入口仅显示在“兑换”页面，默认固定四位口令为 `2580`。口令通过 PBKDF2-SHA256 加盐摘要保存在本机，仅用于防止儿童误触。
- 忘记家长密码时，必须先正确回答一道随机六年级数学题，才可设置新的四位数字密码。

## 内容包

家长中心支持导入 `ContentPackV1` JSON 文件。示例见 `public/content-pack-example.json`。

必填字段：

- 内容包：`schemaVersion: 1`、唯一 `id`、`title`、`contentVersion`、非空 `items`。
- 内容项：唯一 `id`、`module`、`kind`、`title`。
- `module` 可选：`guoxue`、`literacy`、`math`、`english`、`writing`、`science`。
- `kind` 可选：`poem`、`classic`、`character`、`math-choice`、`letter`、`word`、`reader`、`trace`、`science`。

内容包采用事务写入：校验或写入任一条失败时，不会留下部分数据。RAZ 绘本只提供书目、正版链接与进度管理框架，请勿导入未获授权的原书页面或音频。

## AI 一句话新增资料

家长中心的“数据 → 管理全部资料”支持两种新增方式：手工新增，以及“AI 一句话新增”。家长只需描述需要的资料，例如“增加一道适合 5 岁孩子的 10 以内加法选择题，主题是分享苹果”，服务端会调用 DeepSeek 自动填写与手工新增相同的全部字段。

- 默认使用官方模型标识 `deepseek-v4-flash`，可通过 `DEEPSEEK_MODEL` 调整。
- 在服务端 `.env` 中配置 `DEEPSEEK_API_KEY`；不要使用 `VITE_` 前缀，密钥不会进入浏览器构建。
- 生成结果会先进入原有编辑表单，不会自动保存。服务端会校验字段完整性、模块和类型、年龄、选择题选项与答案等，家长仍需核对原文、答案和事实后再保存。
- 未明确提供的正版资源链接不会由模型自行编造。

## 主要规则

- 默认周一至周五为学习日，每周完成任意 5 个完整学习日可获得 5 星光和 1 宝石。
- 家长可设置孩子年龄、数学起始阶段和英语起点，并为每个开启的模块设置每日 1–10 个新内容。排课先筛选适龄内容；“还需练习”次日复习，“需要提示”3 天后复习，独立完成后按第 1、3、7、14、30 天逐步拉长间隔。
- 数学在当前阶段独立完成 10 个不同内容后进入下一阶；选择题保存首次作答、尝试次数和错误次数。非选择题由孩子或家长记录“独立完成／需要提示／还需练习”。
- 国学、识字、数学、英语、科学模块完成后分别获得 2 星光、1 根胡萝卜和 2 经验；控笔获得 1 星光、1 根胡萝卜和 1 经验。奖励余额和兑换价格均为整数，历史半根胡萝卜余额会记录补齐流水。
- “听音乐10分钟”需要 20 星光，申请后由家长确认兑换。
- 同一日期、模块和任务使用固定完成键，重复点击或刷新不会重复发奖。
- 每 100 经验提升一级宠物外观；完成 5、20、50、100、200 个模块时获得里程碑勋章。
- 首页优先显示“开始学习／继续学习”，并回到当天最近使用且尚未完成的模块。
- 英语字母课按“大写字母—小写字母—英文例词—例词中文意思”分段朗读，相邻内容至少间隔 1 秒。
- 科学讲解按问题、方法、结果和解释分段朗读，正在播放的内容同步高亮，结束或切换课程后清除高亮。
- 识字课显示并朗读每个内置汉字的一个常用组词；英语单词课先朗读英文，再朗读对应的中文释义。
- 控笔课默认同步当天识字任务的汉字（含复习字），提供浅色字形与田字格自由描写，支持整字重写和完成确认；关闭识字模块后按控笔自身内容排课。
- 科学课统一展示科学问题、观察方法、观察结果以及过程与结果解释，并支持完整朗读。
- 数学题支持在线读题；数字探索继续支持 ±1、±10、滑动选数、随机数字、中英文展示、百位里程碑庆祝和在线中英文整句朗读。

## 在线语音朗读

默认模型已切换为 `qwen-audio-3.1-tts-flash`，中文音色为 `longanhuan_v3.1`；此前发布的 3 篇长版录音仍保留原模型音频，不重复产生合成费用。配置模板见 [.env.example](.env.example)，详细接入与部署见 [在线语音配置](docs/在线语音配置.md)。

服务端 `TTS_PROVIDER` 可设置为 `qwen`、`doubao`、`minimax`。配置修改后重启服务即可切换，密钥不进入前端构建。数字按完整中英文文本合成，汉字、字母、国学和科学讲解统一调用在线接口；已删除离线音频、生成脚本和词元拼接。断网时课程与进度仍可使用，朗读显示联网提示。

生产环境使用 Node.js 22.16+，运行 `pnpm build` 后用 `pnpm start` 启动（默认端口 80；示例配置为 8080）。Docker 已包含 Node 服务。纯静态 ZIP 不包含语音服务。

## 故事屋

首页「故事时间」可进入故事屋，收听 40 篇分龄故事，其中幼儿园阶段 20 篇。支持筛选、播放进度、续听、收藏、倍速、睡眠定时和家长时长设置。达到每日上限时，当前故事可听完，随后停止。故事进度和收听记录进入本地及家庭云备份，故事正文和 MP3 不进入家庭快照。

40 篇内置故事音频存放在阿里云 OSS 的 `lexue/stories/builtin/`，应用包仅保留故事文字、时长和逐句时间点。播放、拖动、续听和倍速时，正在朗读的句子会高亮。

家长登录后可在“家长中心 → 故事”输入主题，通过 DeepSeek 生成原创故事草稿。草稿不会自动发布；家长检查并保存后可启动后台配音，系统逐句使用已配置的 TTS 模型生成音频、合并 MP3、记录高亮时间点，并保存到 `lexue/stories/families/<family-id>/` 私有目录。家长试听并手动发布后，对应孩子才能在故事屋看到。

重新制作内置音频可运行 `node --env-file=.env scripts/build-story-audio.mjs`，随后运行标准化、发布校验与 `pnpm stories:upload`。音频制作文件保存在忽略的 `.cache/story-production/`，不会重新进入应用包。方案与内容规则见 [故事屋 MVP 产品方案](docs/故事屋MVP产品方案.md)。
