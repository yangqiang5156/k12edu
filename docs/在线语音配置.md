# 在线语音配置

## 1. 千问（默认）

复制根目录 `.env.example` 为 `.env`，填写北京地域的 `QWEN_API_KEY` 和 `QWEN_WORKSPACE_ID`（工作空间 ID，不是名称）。在百炼开通对应模型权限。默认模型 `qwen-audio-3.0-tts-flash`，默认音色 `longanhuan_v3.6`，可通过 `QWEN_TTS_MODEL`、`QWEN_TTS_VOICE` 修改为同系列支持的模型和音色。

使用当前官方工作空间接口 `/api/v1/services/audio/tts/SpeechSynthesizer`，合成后由服务端下载 WAV 再返回浏览器，不向前端暴露密钥和临时文件地址。

## 2. 豆包

设置 `TTS_PROVIDER=doubao`，填写新版控制台 `DOUBAO_API_KEY`。旧版凭证可填写 `DOUBAO_APP_ID` 和 `DOUBAO_ACCESS_KEY`，同时留空新版 Key。通过 `DOUBAO_TTS_RESOURCE_ID` 与 `DOUBAO_TTS_VOICE` 配置模型资源和音色；两者必须匹配且账号已经开通。默认使用 `seed-tts-2.0` 与 Vivi 2.0 音色。

使用 V3 HTTP SSE 接口，服务端收齐并校验结束状态后返回 MP3。这里处理的是同一次合成的传输块，不再拼接数字音频片段。

## 3. MiniMax

设置 `TTS_PROVIDER=minimax`，填写国内开放平台 `MINIMAX_API_KEY`。默认 `speech-2.8-turbo`，可通过 `MINIMAX_TTS_MODEL` 切换 HD 等支持型号，通过 `MINIMAX_TTS_VOICE` 修改音色 ID。使用同步 HTTP API，返回 MP3。

## 4. 开发与部署

开发运行 `pnpm dev`，预览运行 `pnpm build` 后 `pnpm preview`；二者均读取根目录 `.env`，重启生效。生产可运行 `pnpm start`，或使用项目 Docker 镜像。密钥不能以 `VITE_` 开头，也不能写入浏览器设置、代码或镜像。

现有 Docker Compose 部署：在服务器 `compose.yaml` 所在目录创建 `.env.tts`，内容参照根目录 `.env.example`，填入服务商配置；文件权限设为 600，再执行 `docker compose up -d --force-recreate lexue`。该文件与自动发布写入的 `.env` 分离，后续发布不会覆盖密钥。需要 Docker Compose 2.24+；容器端口固定为 80，不受示例 PORT 影响。没有配置时页面仍能打开，朗读提示缺少配置。

子目录部署沿用 `deploy/baota-lexue.conf` 的 `/lexue/` 反向代理，浏览器请求 `/lexue/api/tts`，服务器转发到容器 `/api/tts`。静态 ZIP 仅包含前端，必须另配同源语音接口。

## 5. 行为与限制

每次朗读最多 3000 个字符。服务端每进程最多 3 个同时请求、每分钟最多 60 次；超出后提示稍后重试。单次合成和下载共 45 秒超时。失败不会退回设备 TTS。切题、关闭弹框或启动新朗读会取消旧请求与播放。

当前不持久保存音频，每次点击会发起合成并计费。PWA 不预缓存语音，更新后 Workbox 移除旧预缓存清单中的音频。上线公网时应按实际访问规模增加网关鉴权与用量限制，当前限流不是用户身份认证。

尚未提供真实 API 凭证时，只能验证模拟协议与错误路径；请在配置后试听多音字、古诗停顿、中英切换与手机播放。
