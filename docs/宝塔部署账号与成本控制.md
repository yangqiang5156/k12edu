# 宝塔部署账号、PostgreSQL、OSS与成本控制

本方案保留浏览器 IndexedDB 作为离线学习数据层，同时增加 PostgreSQL 云端账号与同步层。语音采用浏览器缓存、本机持久目录和阿里云 OSS 三级缓存。孩子不需要登录；家长登录后获得换机恢复、多孩子档案和自动云同步。

## 1. 部署组成

| 组件 | 用途 | 推荐管理方式 |
| --- | --- | --- |
| 乐学容器 | 页面、账号 API、同步、限额、TTS | 宝塔 Docker → Compose |
| PostgreSQL 17+ | 家庭、家长、孩子、设备、快照、额度、用量 | 宝塔 PostgreSQL 插件，或 `compose.postgres.yaml` |
| 本机 `data/` | OSS异常时的语音缓存兜底 | 宝塔文件管理与计划任务备份 |
| 阿里云 OSS | 跨实例共享语音缓存 | 阿里云 OSS 控制台；密钥在宝塔部署目录管理 |

应用启动时会自动执行幂等的 `CREATE TABLE IF NOT EXISTS`。生产环境设置 `DATABASE_REQUIRED=true` 后，数据库不可用会阻止应用带病启动，并让健康检查失败触发原有回滚。

## 2. 使用宝塔 PostgreSQL 插件

1. 在宝塔软件商店安装 PostgreSQL 17 或面板支持的稳定版本。
2. 创建数据库 `lexue` 和专用用户 `lexue`，生成独立强密码。
3. 只允许应用所在服务器访问数据库端口；同机部署不要向公网开放 5432。
4. 将 `deploy/runtime.env.example` 复制到生产部署目录并命名为 `.env.runtime`。
5. 设置：

```dotenv
DATABASE_URL=postgresql://lexue:实际密码@宿主机可达地址:5432/lexue
DATABASE_REQUIRED=true
SESSION_SECRET=至少32字节随机字符串
ADMIN_EMAILS=你的家长账号邮箱
```

Docker 容器连接宿主机 PostgreSQL 时，`127.0.0.1` 指向容器本身。可使用宝塔服务器的 Docker 网桥地址或把数据库放入同一个 Compose 网络。不要把 PostgreSQL 直接开放到公网。

生成会话密钥：

```bash
openssl rand -base64 48
```

`.env.runtime` 必须设置为 `600` 权限。现有自动发布只更新 `.env` 中的镜像标签和端口，不会覆盖 `.env.runtime`。

## 3. 完全由宝塔 Docker Compose 管理

如果不使用宝塔 PostgreSQL 插件，可在宝塔 Docker → Compose 中导入 `compose.postgres.yaml`。启动时明确传入运行环境文件：

```bash
docker compose --env-file .env.runtime -f compose.postgres.yaml up -d
```

`.env.runtime` 还需要包含：

```dotenv
LEXUE_IMAGE=你的不可变版本镜像
LEXUE_PORT=8081
POSTGRES_DB=lexue
POSTGRES_USER=lexue
POSTGRES_PASSWORD=数据库强密码
```

PostgreSQL 数据保存在 `postgres-data/`，语音本地缓存保存在 `data/`。升级应用时不得删除这两个目录。

如果线上应用已经由独立 Compose 管理、不希望替换其配置，可使用 `compose.postgres-only.yaml` 单独启动 PostgreSQL。将 `postgres.env.example` 复制为 `.env.postgres` 并填写强密码；该配置会把数据库接入现有 `lexue_default` 内网，不映射宿主机或公网端口，并可在宝塔 Docker 页面直接管理。

## 4. 配置阿里云 OSS

1. 创建私有 Bucket，选择与服务器相同地域。
2. 创建只允许该 Bucket 指定前缀读写的 RAM 用户，不要使用主账号 AccessKey。
3. 权限至少包含 `GetObject`、`PutObject`，资源范围限制为 `lexue/tts/*`。
4. 同地域阿里云服务器可设置 `OSS_INTERNAL=true`；其他环境保持 `false`。
5. 在 `.env.runtime` 填写：

```dotenv
OSS_REGION=oss-cn-hangzhou
OSS_BUCKET=你的Bucket
OSS_ACCESS_KEY_ID=RAM用户Key
OSS_ACCESS_KEY_SECRET=RAM用户Secret
OSS_INTERNAL=true
OSS_TTS_PREFIX=lexue/tts/
```

Bucket 保持私有即可，浏览器不会直接访问 OSS。应用先查本机缓存，再查 OSS；都没有时才调用语音供应商。OSS 写入失败不会中断孩子朗读，音频仍会保存在本机目录。

## 5. 额度与熔断

推荐初始值：

```dotenv
GUEST_TTS_DAILY_LIMIT=30
GUEST_AI_DAILY_LIMIT=0
ACCOUNT_TTS_DAILY_LIMIT=300
ACCOUNT_AI_DAILY_LIMIT=20
TTS_PER_MINUTE_LIMIT=30
AI_PER_MINUTE_LIMIT=5
TTS_IP_PER_MINUTE_LIMIT=60
AI_IP_PER_MINUTE_LIMIT=10
TTS_GLOBAL_DAILY_UPSTREAM_LIMIT=5000
AI_GLOBAL_DAILY_LIMIT=500
TTS_10K_CHARACTERS_ESTIMATED_COST=0
AI_MILLION_TOKEN_ESTIMATED_COST=0
```

- 游客不能使用 AI 新增资料。
- 账号或设备达到日额度后返回明确提示。
- 全站上游调用达到硬上限后停止新的付费调用，缓存命中的语音仍可播放。
- 达到全站硬上限会写入管理后台告警；管理员可查看7日用量、缓存命中情况和按配置单价计算的预估费用。
- 管理员可调整家庭额度、停用异常账号，并发布、更新、下架官方 `ContentPackV1` 版本。
- `ADMIN_EMAILS` 中的邮箱注册后自动取得管理员权限。若账号已提前注册，需要在 PostgreSQL 中把对应 `parent_users.is_admin` 更新为 `true`。

## 6. 云同步行为

- 本机 IndexedDB 仍是孩子操作时的第一写入点，不会因为网络抖动阻塞学习。
- 登录后，本机完整备份在数据变化约2.5秒后上传。
- 云端快照使用版本号做乐观锁；另一台设备上传了新版本时，旧设备不会静默覆盖。
- 从云端恢复前会自动下载一份本机恢复前备份。
- 一个家庭可以创建多个孩子档案；切换孩子时需明确确认恢复对应云端数据。
- 家长可以导出完整云端家庭数据；注销时必须再次输入账号密码，确认后删除家庭、孩子、快照、额度和用量数据，本机学习数据仍保留。

当前同步采用版本化快照，适合现阶段单家庭低并发使用。若以后需要两台设备同时离线学习再合并，应把 `learning_events` 和奖励流水升级为逐事件增量同步，快照继续作为快速恢复点。

## 7. 宝塔反向代理与安全

沿用 `deploy/baota-lexue.conf`。必须保证 `/lexue/api/` 与页面同源，不要为 API 添加跨域响应头。建议在宝塔防火墙和 Nginx 中再增加每 IP 的连接频率限制，但不要用 Nginx 限流替代应用内设备/家庭额度。

健康检查：

```bash
curl -fsS http://127.0.0.1:8081/healthz
```

账号 API 快速检查：

```bash
curl -fsS -X POST http://127.0.0.1:8081/api/session/guest \
  -H 'Content-Type: application/json' \
  -d '{"deviceId":"test-device-1234567890"}'
```

## 8. 备份与恢复

- PostgreSQL：使用宝塔计划任务每天执行逻辑备份，并保留至少7个每日版本和4个每周版本。
- `data/`：每天增量备份；即使丢失也只会增加后续语音重新合成，不影响学习记录。
- OSS：启用版本控制或生命周期规则；不要自动清理仍在使用的 `lexue/tts/` 对象。
- `.env.runtime`：单独加密备份，不要放入数据库备份或 Git 仓库。

上线前应实际完成一次数据库备份恢复演练、OSS断连降级验证、账号停用验证和全站额度熔断验证。
