# 安全开放实施与上线核对（2026-10-11）

本次完成本地实现与回归，尚未发布到阿里云，尚未改变 GitHub 仓库可见性。原来的两份检查报告记录的是修复前情况。代码通过测试不能替代生产代理、OSS/RAM权限与供应商账单设置验证，也不代表绝对安全。

## 1. 公众使用方式

- 公众可注册普通家庭账号、使用已有资料、家庭同步、播放内置故事；注册不会按 ADMIN_EMAILS 自动授予管理员权限。
- 新账号和升级时已有家庭默认 `paid_enabled=false`。新语音合成、AI资料/故事生成、故事配音需管理员显式开启；访客只使用已缓存的课程语音，新合成被拒绝。课程语音缓存未命中时前端会提示，客户端原有浏览器语音降级仍保留。
- 家庭音频使用30分钟会话绑定试听票据，退出、禁用家庭/设备后失效；链接过期需刷新列表。内置音频只允许当前版本白名单，由应用代理播放，浏览器不获得 OSS 签名链接。
- 管理后台新增“启用/关闭在线生成”。关停全站新付费请求可设置 `PAID_SERVICES_ENABLED=false` 并重启，正在供应商执行的请求仍可能已扣费。

## 2. 限流和预算

生产环境要求 PostgreSQL：每次调用前在数据库事务内预占，所有副本共用额度。失败、取消和 AI 重试均保留供应商预占额，避免失败后无限重试；额度按 UTC 日期重置。供应商成功返回的实际 token 用于后台统计，限额使用输入 JSON UTF-8字节数加最大输出 token 的保守预留值，不是精确人民币账单。

| 范围 | 默认值 |
| --- | --- |
| 家庭课程/故事逐句朗读业务额度 | 300次/日（包含缓存命中）；后台配音与课程共用 |
| 家庭AI业务额度 | 20次/日；故事再加3次/日，失败也占故事额度 |
| 全站朗读业务额度 | 10000次/日，120次/分钟 |
| 全站TTS实际请求、字符 | 5000次/日、50000字/日；家庭10000字/日 |
| 全站AI实际请求、保守token预留 | 500次/日、200000/日；家庭30000/日 |
| 实际供应商并发 | TTS 3、AI 2；数据库租约，崩溃最多2分钟后释放 |
| 故事配音队列 | 全站1个后台worker、最多100个待处理任务、每家庭1个活跃任务及3次提交/小时 |
| 内置/家庭音频下载 | 全站180次/分钟、10000次/日、1GiB/日；每IP60次/分钟、1000次/日、100MiB/日 |
| 公开账号注册 | 每IP10次/15分钟，全站200次/日 |
| 访客会话创建 | 每IP120次/15分钟，全站10000次/日 |
| 同步与档案 | 家庭60次同步/分钟，最多10个孩子、50个未归档故事 |

音频会先预占对象请求次数，再预占实际响应范围的字节；HEAD计次数不计正文流量，取消下载不退额。上述流量上限不包括代理协议开销、供应商音频临时下载、TTS缓存读写、用户上传及外部直接访问OSS产生的费用，必须配合云端权限和费用告警。

未登录请求不会占用生成接口的本地共享计数器。所有API入口另有IP请求限流、全站600次/分钟入口限流及每个应用副本40个在途请求上限。限流和预算存储异常时拒绝请求，不回退成无限额度；未配置安全服务的生成中间件也拒绝调用。

## 3. 其他防护

退出在服务器删除会话；旧的无sessionId登录令牌在升级后失效，用户需重新登录。数据库部署必须使用至少32字符会话密钥。每设备限制保留最近会话，过期会话和分钟窗口自动清理。

请求有正文大小/读取超时，供应商响应最大20MiB，供应商请求及音频进程有超时；ffprobe改为顺序处理，失败任务删除临时音频，worker清理超过24小时的残留目录。本地TTS缓存默认512MiB/7天并自动淘汰，OSS缓存生命周期由云端配置。

生产响应加入CSP、禁止页面嵌入、同源写请求校验；服务端5xx不向外返回供应商/数据库内部信息。家庭音频与新OSS对象使用私有缓存策略。容器模板增加CPU、内存、进程数及日志滚动限制；开发服务器只监听本机，新付费调用需要显式 `ALLOW_LOCAL_PAID_SERVICES=true`。

## 4. 上线前操作

1. 备份生产数据库和部署目录私有环境文件；核对现有 `parent_users.is_admin=true` 的账号是否都是你本人授权。修复阻止新注册提权，但不自动删除既有管理员。
2. 轮换旧 `.env.example` 孤立Git对象出现过的OSS凭据，并按需要轮换其他旧密钥。使用专用RAM子账号，仅授予所需bucket/prefix的GetObject/PutObject/DeleteObject；不授予管理RAM、其他bucket或账号管理员权限。
3. OSS桶保持私有；检查历史对象单独ACL不能公开，并清理/改正旧的public缓存头。停用外部公开 `STORY_AUDIO_PUBLIC_BASE_URL`；本次API已不使用此地址，但该地址/旧签名链接仍可能在云端独立可访问。可等待旧签名最长2小时失效，也可轮换签名凭据使其提前失效。建立TTS对象生命周期，并设置OSS用量告警/账单预算。Referer防盗链只能辅助，不能代替私有ACL。
4. 配置 `.env` 的PUBLIC_ORIGIN与APP_BASE_PATH，更新宝塔代理片段：X-Real-IP与X-Forwarded-For都由代理覆盖为remote_addr。应用只信任实际直接连接它的代理IP，不读取客户端自报的X-Forwarded-For。Docker端口映射通常使应用看到桥接网关地址，需填入 `TRUSTED_PROXY_IPS` 的准确IP；不要填任意网段或 `*`。前面还有CDN时先在Nginx只信任CDN官方出口，再正确恢复remote_addr。
5. 复制新增预算变量并按承受的账单调整；核对百炼/DeepSeek/其他语音供应商的模型权限、配额和费用告警。应用预算不能替代云平台预算，其他应用复用相同密钥也会产生费用。
6. 部署新版本。数据库自动添加新表和家庭生成开关；已有内容保留，但已有家庭生成开关默认关闭，会话需重新登录。禁止只回滚应用而忽视旧版仍可能恢复漏洞；出现问题可先关闭注册/付费服务。
7. 首个管理员必须先自行注册，再在受信服务器终端使用镜像内命令授权（这不是公开HTTP接口）：

```sh
# 部署目录；私有 .env 由 compose传入容器
# 将邮箱替换为你自己已注册并确认归属的地址
docker exec lexue node server/manage-access.mjs --email 你的邮箱 --admin --paid
# 启用普通家庭 / 撤销生成权限
docker exec lexue node server/manage-access.mjs --email 已核实邮箱 --paid
docker exec lexue node server/manage-access.mjs --email 已核实邮箱 --no-paid
# 撤销管理员
docker exec lexue node server/manage-access.mjs --email 已核实邮箱 --no-admin
```

8. 上线验证：未登录401，访客/新家庭新合成及AI403，非管理员后台403；批准家庭少量成功；退出后旧会话和家庭试听链接401；音频Range206且Location中无OSS签名；过额429，伪造XFF不改变限流主体；检查CSP与代理实际IP。严禁对付费接口做生产压测。
9. 最后才开放GitHub：提交前检查暂存区与可达历史，排除 `.env`、`.git`副本、私有备份与构建输出；保留既有审计报告中的“孤立对象不是历史提交泄漏”边界。本轮没有重写Git历史、删除凭据或公开仓库。

GitHub持续集成和标签发布已加入固定版本、SHA256校验的Gitleaks扫描，检出完整历史并扫描全部可达提交及当前待公开文件；日志对凭据完整脱敏。私有 `.env` 和被忽略缓存不被复制到扫描临时目录，原仓库中不可达Git对象仍按此前报告处理。扫描器来源：[Gitleaks v8.30.1官方发布](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1)。

公众大规模访问还需在阿里云/CDN/WAF设置入口防刷、连接限额和费用告警；应用层额度只能保护进入应用后的请求，不能承诺抵抗分布式拒绝服务或云账户额度之外的支出。

## 5. 验证

常规测试：`pnpm test`。构建：`pnpm build`。实际数据库并发/迁移测试：将 `SECURITY_TEST_DATABASE_URL` 指向独立数据库，名称必须包含 `lexue_security_test`，再运行 `pnpm test`。该测试会清空独立测试库数据，绝不能指向生产库。

新增回归覆盖伪造代理IP、并发最后额度、失败及重试计入预算、全站并发、匿名请求占槽、付费准入、退出撤销、OSS白名单和流量预算；数据库集成进一步验证跨服务实例共享窗口/预算、注册不提权、手工故事配音准入与并发入队，以及退出后家庭试听失效。

生产环境的RAM策略、OSS实际ACL、供应商账户预算、可信代理IP及公网修复效果未在本次本地实现中核实，完成上述上线步骤后才能判断是否满足公开开放条件。
