# 朗读权限与 iOS 排查

## 在线朗读条件

- 浏览器已经保存的课程音频可以直接播放。
- 服务端已有音频缓存可供正常会话读取，仍受访客/家庭每日次数、IP 与全局流量限制。
- 缓存未命中时需要登录家庭账号，家庭处于正常状态，管理员已启用“在线生成”；全局开关未关闭、家庭及全站预算有余量、服务商配置和额度可用。
- 管理员可在家长中心的运营管理中为指定家庭“启用在线生成”。这个开关同时涵盖语音和 AI，不应为所有访客打开。在线语音开通后仍需要在手机登录该家庭账号。

## iOS 桌面图标模式

- 网络准备音频后，系统可能不允许自动播放。看到“在线语音已准备好，请再点一次播放在线语音”时，再点课程朗读按钮即可；两分钟内保留本次音频，重试不重复生成。
- 权限不足或额度不足时显示具体原因；点击“使用设备朗读”才同步启动设备声音。
- 课程下方可切换在线/设备朗读方式，数字探索也有同样的入口。
- 设备语音未触发开始事件时会显示失败，不再直接显示成功。
- 设备朗读显示已开始仍无声时，检查静音开关/静音模式、媒体音量和蓝牙输出。网页无法确认声音实际从扬声器传出，也无法检测所有系统静音状态。
- 声音不可用时，在 iPhone 设置 → 辅助功能 → 朗读内容（部分系统版本叫“朗读与语音”）→ 声音，检查中文和英文声音；必要时下载。可以从 Safari 打开同一地址对比，确认是否仅桌面模式异常。

## 验证边界

自动回归覆盖异步播放被拒绝后同步重试、无重复请求、系统语音声音选择、音频会话模式、缺少开始事件、声音缺失与超时取消。模拟事件与桌面浏览器验收不能替代真实 iPhone 的声音验证。
