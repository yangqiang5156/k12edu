# 乐学自动发布与阿里云部署

## 发布流程

正式版本使用不可变标签。推送 `vX.Y.Z` 标签后，GitHub Actions 会依次：

1. 安装依赖、运行测试并生产构建。
2. 使用已经生成的 `dist/` 构建轻量运行时镜像，避免在 Docker 中重复安装依赖和构建前端。
3. 将版本镜像推送到 GitHub Container Registry（GHCR）作为灾备，同时生成压缩镜像归档。
4. 创建包含静态部署 ZIP 与 SHA-256 的 GitHub Release。
5. 通过 SSH 将压缩镜像直接传送到阿里云，校验 SHA-256 后本地导入、启动容器并执行健康检查；生产机不再跨境访问 GHCR。
6. 健康检查失败时自动恢复部署前使用的镜像。

## GitHub Secrets

在仓库 `Settings → Secrets and variables → Actions` 中配置：

| 名称 | 必填 | 说明 |
| --- | --- | --- |
| `ALIYUN_HOST` | 是 | 阿里云服务器公网 IP 或域名 |
| `ALIYUN_USER` | 是 | 有权运行 Docker 的 SSH 用户 |
| `ALIYUN_SSH_PRIVATE_KEY` | 是 | 专用部署私钥的完整内容 |
| `ALIYUN_SSH_KNOWN_HOSTS` | 是 | 本机执行 `ssh-keyscan -H 服务器地址` 得到的服务器主机公钥记录 |
| `ALIYUN_SSH_PORT` | 否 | SSH 端口，默认 `22` |
| `ALIYUN_DEPLOY_PATH` | 否 | 服务器部署目录，默认用户主目录下的 `lexue` |
| `ALIYUN_APP_PORT` | 否 | 映射到服务器的 HTTP 端口，默认 `8080` |

服务器需要预先安装 Docker Engine 与 Docker Compose 插件，部署用户需能直接执行 `docker`。若已有 Nginx/宝塔，可将域名反向代理到 `127.0.0.1:8080`，并为域名配置 HTTPS。

当前生产环境约定为：

- SSH：`aliyun-dev` 对应的阿里云服务器。
- 部署目录：`/root/lexue`。
- 容器仅监听：`127.0.0.1:8081`，不直接暴露公网端口。
- 访问地址：`https://ai.liqi123.com/lexue/`。
- 宝塔 Nginx 使用 `location ^~ /lexue/` 反向代理，避免站点原有 JS/CSS/图片正则缓存规则截获 PWA 静态资源。

对应配置模板位于 `deploy/baota-lexue.conf`。应在容器健康后复制到 `/www/server/panel/vhost/nginx/extension/ai.liqi123.com/lexue.conf`，执行 `nginx -t` 成功后再平滑重载。

## 首次发布

确认 `package.json`、`CHANGELOG.md` 和标签版本一致，然后执行：

```bash
git switch main
git pull --ff-only
pnpm test
pnpm build
git tag -a v0.1.0 -m "乐学 v0.1.0"
git push origin main
git push origin v0.1.0
```

后续版本先更新版本号和更新日志，再创建新的标签，例如 `v1.0.1`。不要移动或覆盖已经发布的版本标签。

## 缓存与客户端更新

- Vite 的 JS/CSS 文件名包含内容哈希，服务器可长期缓存且不会把新旧内容混淆。
- `index.html`、`sw.js` 和 PWA 清单禁止长期缓存，每次访问都会向服务器确认。
- Service Worker 会立即接管新版本、删除旧版本缓存，并在应用回到前台及每 5 分钟检查一次更新。
- 应用发现新版本后展示“立即更新”，用户确认后刷新到新版本；IndexedDB 学习数据不会因更新镜像而清空。

## 回滚

自动部署失败会尝试恢复部署前镜像。服务器会保留已经导入的历史版本，人工回滚不需要访问 GHCR。在服务器部署目录执行：

```bash
sed -i.bak 's#^LEXUE_IMAGE=.*#LEXUE_IMAGE=ghcr.io/<账号>/<仓库>:v0.1.0#' .env
docker image inspect ghcr.io/<账号>/<仓库>:v0.1.0
docker compose -f compose.yaml up -d --pull never lexue
docker inspect --format '{{.State.Health.Status}}' lexue
```

请将示例版本替换为确认可用的旧版本。发布期间不要执行镜像清理，以保留快速回滚能力。
